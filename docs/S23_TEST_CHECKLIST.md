# S23 설치 후 테스트 체크리스트

SuperDialer를 갤럭시 S23에 설치하고 기본 전화 앱으로 지정한 뒤 확인할 항목입니다.

## 시작하기 전에 (꼭 읽기)

- **비상용 연락 수단을 확보**하세요. 다른 폰이나, 기본 전화 앱을 삼성 전화로 되돌리는 방법을 알고 있어야 합니다.
- **테스트 중 112/119 등 긴급전화는 걸지 마세요.** 긴급전화 자체는 시스템이 처리하지만, 테스트 목적으로 걸면 안 됩니다.
- 실제 연락처로 발신하는 테스트는 **본인 번호나 상대가 알고 있는 번호**로만 하세요. (한 번 모르는 사이에 실제 발신이 나간 적이 있습니다.)
- 기본 전화 앱 **되돌리기**: 휴대폰 설정 > 앱 > 기본 앱 > 전화 앱 > "전화"(삼성) 선택.

## 설치

```bash
./gradlew installDebug
# 또는
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- 폰에서 "출처를 알 수 없는 앱" 또는 Play Protect 경고가 나오면 허용
- 삼성 Auto Blocker가 켜져 있으면 설치가 막힐 수 있음 (설정 > 보안 및 개인정보 보호 > Auto Blocker)

## A. 첫 실행 · 권한

- [ ] 처음 실행하면 알림 권한 팝업 → 허용
- [ ] "기본 전화 앱으로 설정해 주세요" 안내 화면이 보임
- [ ] "기본 전화 앱으로 설정" → 시스템 팝업에서 SuperDialer 선택 → 설정
- [ ] 거부하면 안내 문구 + "다시 시도"/"계속"이 나오고, 설정 탭에서 다시 요청 가능
- [ ] 설정 탭: 기본 전화 앱 "SuperDialer가 기본 전화 앱입니다"
- [ ] 최근기록/연락처 탭에서 권한 요청이 뜨고 허용하면 목록이 보임
- [ ] 설정 > 전체 화면 알림이 "허용됨" (Android 14+, 아니면 눌러서 허용)

## B. 수신

- [ ] 다른 폰으로 전화 → **화면 켜진 상태**: 상단 알림(받기/거절), 알림을 누르면 수신 화면
- [ ] **잠금 화면 / 화면 꺼짐** 상태: 전체 화면 수신 화면이 켜지며 표시
- [ ] 벨소리가 울림 (소리는 시스템이 재생)
- [ ] 저장된 번호는 이름, 저장 안 된 번호는 번호가 표시
- [ ] 받기 → 통화 중 화면, 타이머 증가
- [ ] 거절 → 상대에게 거절 처리, 최근기록에 "거절"
- [ ] 메시지로 거절 → 문구 선택 → 상대에게 문자 전송 (문자 앱 기본 설정에 따라 동작 여부 다를 수 있음)
- [ ] 받지 않고 끊김 → 부재중 알림, 누르면 최근기록 탭

## C. 발신

- [ ] 키패드에서 번호 입력 → 통화 버튼 → "연결 중..." → 연결 후 타이머
- [ ] 연락처 상세/최근기록의 초록 전화 버튼으로 발신
- [ ] 다른 앱(카카오톡 등)의 전화번호 링크(tel:) → SuperDialer 키패드에 번호가 채워짐
- [ ] 상대가 끊으면 "통화 종료"가 잠깐 보이고 화면이 자동으로 닫힘

## D. 통화 중 기능

- [ ] 음소거 (상대가 내 목소리를 못 듣는지)
- [ ] 스피커 on/off (소리 경로 변경)
- [ ] 키패드 DTMF (ARS 숫자 입력)
- [ ] 보류 / 보류 해제
- [ ] 통화 종료 버튼
- [ ] 통화 중 홈 버튼으로 나가기 → 알림창에 "통화 중" 알림(종료 버튼 포함) → 누르면 통화 화면 복귀
- [ ] 블루투스 이어폰 연결 시 소리 경로 (스피커 버튼 동작 확인)

## E. 통화 대기 · 여러 통화 (에뮬레이터로 검증 못 함)

- [ ] 통화 중 두 번째 전화가 오면 수신 화면이 두 번째 통화로 바뀜
- [ ] 받으면 첫 통화가 보류되고 "보류 중" 배너 표시, 배너를 누르면 전환
- [ ] 통화 추가 → 키패드에서 새 번호 발신 → 기존 통화 보류
- [ ] 병합 버튼이 나타나면 눌러서 다자간 통화 ("다자간 통화"로 표시)

## F. 차단 · 기록 · 연락처

- [ ] 최근기록에서 길게 눌러 차단 → 설정 > 차단 관리에 번호가 들어감
- [ ] 차단한 번호로 전화가 오면 울리지 않음
- [ ] 차단 해제(휴지통 아이콘)
- [ ] 통화 후 최근기록에 발신/수신/부재중이 맞게 쌓임
- [ ] 연락처 즐겨찾기 토글이 삼성 연락처 앱에도 반영

## G. 문제가 생기면

- 통화 화면이 안 뜸 → 설정 탭에서 기본 전화 앱 상태, 알림 권한, 전체 화면 알림 허용 확인
- 로그 수집: `adb logcat -d | findstr /i "superdialer InCall Telecom"` 결과를 Claude Code에 붙여넣기
- 통화 자체가 안 되면 즉시 기본 전화 앱을 삼성 전화로 되돌리기
