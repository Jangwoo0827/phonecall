SuperDialer

전화 앱 + 내장 웹브라우저 + 내장 게임을 하나로 합친 올인원 안드로이드 앱

최신 APK 받기 (GitHub)

들어 있는 것
  • 키패드(자동완성·단축 다이얼) · 최근기록 · 연락처(그룹·중복 정리) · 통화 화면 · 통화 메모
  • 문자·MMS 보기와 문자 보내기
  • 내장 웹브라우저(시작 페이지, 북마크, 탭 유지, 다운로드)
  • 내장 게임(2048, 스네이크, 벽돌깨기, Crossy Chicks)과 랭킹
  • 선택 사항인 계정: 이메일 또는 Google로 로그인하면 설정·북마크·게임 점수를 다른 폰과 동기화
설치
  1. 위 버튼에서 SuperDialer-vX.Y.Z.apk를 받습니다.
  2. 폰에서 열어 설치합니다(“출처를 알 수 없는 앱” 허용 필요).
  3. 처음 실행하면 기본 전화 앱으로 설정하라는 안내가 나옵니다. 건너뛰어도 대부분의 기능을 쓸 수 있습니다.

스토어에 올리지 않은 앱입니다. 설치한 뒤에는 앱 안에서 새 버전을 받아 업데이트할 수 있습니다.
